# Generated Feature Work

Use this directory for generated PRDs and task lists.

## Naming

- `prd-[feature-name].md` - Product requirements generated with `prompts/ai-dev-tasks/create-prd.md`.
- `tasks-[feature-name].md` - Implementation task list generated with `prompts/ai-dev-tasks/generate-tasks.md`.

Keep root `TASKS.md` as the short active-work dashboard. Link to generated files here when a feature is active.
