# AI Dev Tasks Prompts

Reusable prompts for the PRD-to-task-list workflow.

## Source

- `create-prd.md`: https://github.com/snarktank/ai-dev-tasks/blob/main/create-prd.md
- `generate-tasks.md`: https://github.com/snarktank/ai-dev-tasks/blob/main/generate-tasks.md
- Upstream usage guide: https://github.com/snarktank/ai-dev-tasks/blob/main/README.md

## Local Usage

1. Use `create-prd.md` to generate `tasks/prd-[feature-name].md`.
2. Use `generate-tasks.md` with that PRD to generate `tasks/tasks-[feature-name].md`.
3. Keep root `TASKS.md` focused on the current active task summary.
